# 05_audits-and-reports

存放盤點、稽核、完成度報告與問題紀錄。

- 文件號格式：`AUD-NNN_<kebab-case-title>.md`（盤點／稽核）、`RPT-NNN_<kebab-case-title>.md`（報告）、`BUG-NNN_<kebab-case-title>.md`（問題紀錄）
- 小型 bug fix 若省略了 PRD/PLN，建議至少在此留一則簡短的 `BUG-NNN` 紀錄問題與修法。

完整規則見 [`docs/00_manual-and-index/MAN-000_docs-usage-manual.md`](../00_manual-and-index/MAN-000_docs-usage-manual.md)。
