## 1. 這份文件的用途

RES-001 定出了每一頁要放什麼。本文件把「版型需要、但現在手上沒有」的東西一次列清楚，分三類：

- **圖像**：Logo、照片、書封等。
- **文案**：文案集沒有、或需要客戶確認的文字。
- **動效**：進場、捲動、光感等動態效果需要的規格、元件與素材。

每一項都標了優先級與「沒拿到時怎麼辦」，客戶可以依 §8 的回覆表逐項回覆。

**優先級**

| 等級 | 意思 |
| --- | --- |
| P0 | 沒有就無法上線對應的區塊或頁面 |
| P1 | 有替代做法可以先上線，但品質明顯受影響 |
| P2 | 可延後，不影響這一輪上線 |

## 5. 動效與捲動效果缺口

### 5.1 現況

實測結果：網站目前幾乎沒有動效，而且有三處「以為有、其實沒有」。

| 項目 | 現況 |
| --- | --- |
| `motion` 套件（原 Framer Motion） | 已安裝 v12，全站只有部落格文章彈窗 1 處使用 |
| 捲動觸發的動效 | 0 處 |
| `animate-fadeIn` | 13 個檔案使用，沒有任何 CSS 定義，無效果 |
| `tw-animate-css` | 已安裝但從未載入。shadcn 的手機抽屜、下拉選單、浮層靠它做開合動畫（14 處），目前都是瞬間出現 |
| `shimmer-button` | 兩個動畫未定義；階段 A 後已無任何頁面使用 |
| 有效的動效 | Hero 的 5 個光點閃爍、形象照外圈慢轉、卡片與按鈕的滑入浮起 |
| 減少動態偏好（`prefers-reduced-motion`） | 完全沒有處理 |
| 錨點捲動 | 靠 CSS `scroll-behavior: smooth`；固定頁首的偏移只有 4 處設定 |

### 5.2 目標：三層動效系統

方向是「金色光感、但克制」。動效分三層，數字越大越偏裝飾：

| 層 | 目的 | 例子 | 建議 |
| --- | --- | --- | --- |
| M1 功能 | 讓操作有回饋、狀態切換看得懂 | 選單開合、分頁切換、FAQ 展開、手機底部固定列滑入 | 必做 |
| M2 敘事 | 捲動時引導閱讀順序 | 區塊標題與卡片依序淡入上移 | 必做 |
| M3 品牌光感 | 呈現「金光閃閃」的記憶點 | Hero 光感視差、主按鈕金光掃過、Logo 展翼、數字跳動 | 建議做，強度由客戶決定（見 5.5） |
| M4 裝飾 | 加分但非必要 | 換頁轉場、媒體 Logo 跑馬燈、書封傾斜 | 不建議這一輪做 |

**共用參數**（階段 D 寫入 UI 規範）

| 參數 | 值 |
| --- | --- |
| 快（滑入、按下） | 150ms |
| 標準（淡入、分頁、展開） | 250ms |
| 慢（Hero 進場） | 500ms |
| 環境循環（光點、光暈） | 3–6 秒一輪 |
| 進場位移 | 上移 16px 加淡入 |
| 依序延遲 | 每個元素 70ms，一組最多 6 個 |
| 曲線 | 進場用緩出；分頁指示條用彈性 |
| 觸發 | 元素進入視窗約 10% 時播放一次，不重播 |

### 5.4 開發端的缺口（不需客戶提供）

| # | 缺口 | 做法 |
| --- | --- | --- |
| D1 | 沒有共用的進場元件 | 用 `motion` 做 `Reveal`（單一元素）與 `RevealGroup`（依序）兩個元件，取代無效的 `animate-fadeIn` |
| D2 | shadcn 開合動畫失效 | 在 `app/globals.css` 載入 `tw-animate-css` |
| D3 | 沒有處理減少動態偏好 | 全站包一層動效設定，系統開啟「減少動態」時只保留淡入、取消位移與循環；CSS 的光點與光暈同樣停用 |
| D4 | 沒有捲動偵測 | 頁首陰影、底部固定列、進度線共用一個捲動狀態的 hook |
| D5 | 分頁與展開元件不存在 | 新增 shadcn `tabs`、`accordion`（RES-001 §8.1） |
| D6 | 金光掃過與光暈效果 | 用 CSS 漸層加 `background-position` 動畫實作，不加套件 |
| D7 | 動效套件的載入成本 | 伺服器元件維持不變，只有包了進場效果的區塊才載入 `motion`；採用精簡載入方式 |
| D8 | 未使用的 `shimmer-button` | 移除，或由 D6 取代 |

### 5.6 效能與無障礙底線

動效做完要符合以下條件，階段 D 驗收時逐項檢查：

- 首頁主標題不因進場動畫而延後顯示：標題本身不從透明開始，只做位移，或完全不動。
- 動效只改變位置與透明度，不造成版面跳動。
- 手機（寬度小於 768px）不做視差。
- 同一個畫面內持續循環的動效最多 2 個。
- 系統開啟「減少動態」時，沒有位移、視差、循環與數字跳動。
- 所有動效都不影響鍵盤操作與焦點順序。
