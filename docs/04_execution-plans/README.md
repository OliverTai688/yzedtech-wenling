# 04_execution-plans

存放實作／行動計畫（PLN）。

- 文件號格式：`PLN-NNN_<kebab-case-title>.md`
- 開始實作任何非單純文字/樣式修正的工作前，先在此建立計畫，列出批次、涉及檔案、風險，並標註對應的 PRD 編號（若有）。
- 建立新文件時可複製 [`docs/templates/PLN-TEMPLATE.md`](../templates/PLN-TEMPLATE.md) 作為起點。

完整規則見 [`docs/00_manual-and-index/MAN-000_docs-usage-manual.md`](../00_manual-and-index/MAN-000_docs-usage-manual.md)。
