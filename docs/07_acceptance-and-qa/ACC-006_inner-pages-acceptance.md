## 3. 逐頁驗收清單

開發伺服器：<http://localhost:3100>。建議先用手機寬度（390）看，再看桌機。每頁的提案與說明在 `docs/06_research-and-design/proposals/pages-v2/<頁面>/`。

### 每一頁都要看的四件事

- [ ] 第一個畫面看得出這一頁是什麼、可以做什麼
- [ ] 一個畫面裡不覺得字太多；想看更多時知道要點哪裡
- [ ] 金色按鈕只有一顆，而且是這一頁最該做的事
- [ ] 頁尾前的「上一站／下一站」去的地方合理

## 4. 實機驗收

這一輪和首頁一樣，**只在電腦上的模擬環境測過**。請至少用以下三種各走一次：iPhone 的 Safari、Android 的 Chrome、從 LINE 對話裡點連結開啟的內建瀏覽器。

- [ ] 每一頁沒有左右晃動、沒有被切掉的內容
- [ ] 底部固定的行動列沒有被瀏覽器的工具列蓋住
- [ ] 面板滑出後，背景不會跟著捲動；關掉後回到原本的位置
- [ ] 詳細頁按「私訊官方 LINE」會開啟 LINE，並帶入該頁的名稱
- [ ] 訊號不好的地方（或把手機調成 3G）：頁面出現後，分頁與面板多久才點得動（見 §6 第 1 項）
- [ ] 首頁的項目照 ACC-005 §6
