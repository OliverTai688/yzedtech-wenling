# 07_acceptance-and-qa

存放驗收與 QA 文件（ACC）。

- 文件號格式：`ACC-NNN_<kebab-case-title>.md`
- 功能實作完成後，在此建立可勾選的驗收清單，並引用對應的 PRD／PLN 編號，形成 PRD → PLN → ACC 的可追溯鏈。
- 建立新文件時可複製 [`docs/templates/ACC-TEMPLATE.md`](../templates/ACC-TEMPLATE.md) 作為起點。

完整規則見 [`docs/00_manual-and-index/MAN-000_docs-usage-manual.md`](../00_manual-and-index/MAN-000_docs-usage-manual.md)。
