# 01_product-requirements

存放產品需求文件（PRD）。

- 文件號格式：`PRD-NNN_<kebab-case-title>.md`
- 新增功能、版面調整、內容結構變更時，先在此建立 PRD，再進入 `04_execution-plans` 寫執行計畫。
- 單純文字或樣式微調可省略 PRD。
- 建立新文件時可複製 [`docs/templates/PRD-TEMPLATE.md`](../templates/PRD-TEMPLATE.md) 作為起點。

完整規則見 [`docs/00_manual-and-index/MAN-000_docs-usage-manual.md`](../00_manual-and-index/MAN-000_docs-usage-manual.md)。
