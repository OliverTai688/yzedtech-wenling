## 1. 背景

階段 D 完成後，網站乾淨、不堆字、每頁都有下一步，但各頁是並列的版型，沒有共同的故事；CTA 只有「選需求」與「LINE／預約」兩端，中間沒有承接還沒準備好付費的人。

## 2. 目標

1. 全站有一個明確的主題，首頁讀起來是同一個故事的五個章節。
2. CTA 有深度：由淺到深的承諾，每一階都接得住人，任何一階都能直接跳到預約。
3. 用小元件漸進推進，操作只有捲動與點一下。
4. 補上自製的視覺元素，等客戶素材到位再替換。
5. 每一個行動都量得到。

## 3. 這一輪的硬性限制

| 限制 | 說明 |
| --- | --- |
| **文案只用 docx** | 對訪客顯示的每一句話都必須逐字出自 `Downloads/網站文案集.docx`（轉檔為本機的 `docs/網站文案集.md`）。開發端不撰寫、不改寫、不摘要。docx 沒有對應文字的地方就不放文字，改用數字或圖示，並列為待客戶提供。舊版文案集（v1）不是可用來源。（使用者 2026-10-05 兩次明確指示：「文案只能是我有提供給你的，請勿自行撰寫」「文案必需是這裡面的」） |
| **路由不變** | 不新增、不移除、不改名任何網址與錨點。因此 PLN-005 原訂的 `/ui-kit` 展示頁與 `/start` 新手入門不在這一輪 |
| 不擋路 | 頁面以原生方式捲動；手機不做固定舞台；頁首商城與底部固定列隨時可用（RES-004 §4.2） |
| 不偽造 | 不用 AI 生成的人像代表創辦人或個案；見證在授權前維持隱藏 |
| 速度 | 模擬慢速 4G 手機，首次繪製不慢於 1.5 秒（現為 1.4 秒） |

「文案不變」排除了 RES-004 提到的幾項，留待客戶提供文字後再做：30 秒找起點的引導（題目是新文案）、直播倒數與加入行事曆（需要新的標籤文字與 C12 確認）、預約三步說明、LINE 帶話的問候句。

## 4. 需求

### 4.1 主題與章節

主題「改變地圖」：找到你現在的位置，看見路怎麼走，展翼出發。主題名稱本身不顯示在頁面上（那會是新文案），只體現在結構與視覺。

首頁五章，內容與標題全部沿用既有文字：

| 章 | 內容 | 標題來源 | 錨點 |
| --- | --- | --- | --- |
| 01 | Hero | 眉標「成為你豐盛之路上的翅膀」 | — |
| 02 | 需求入口 | 「為不同階段的你，量身規劃專屬的改變起點」 | `#personas-section` |
| 03 | 三階段＋精選服務 | 「這些技術之間的關係是什麼？可以搭配使用嗎？」（`/about` 原文）、「能量療癒服務｜為你的身心靈量身訂做的解方」 | `#featured-services` |
| 04 | 創辦人＋媒體 | 「在愛與豐盛中綻放靈魂的光芒」 | `#founder`、`#media-section` |
| 05 | 免費資源＋常見問題＋最終行動 | 眉標「免費資源」、「常見問題」 | `#free-resources`、`#home-faq` |

三階段的原文目前只在 `/about`。帶到首頁時維持收合，三個階段的名稱直接可見，內文點開才看。

### 4.2 敘事元件

| 元件 | 行為 | 操作 |
| --- | --- | --- |
| 章節標示 | 每章開頭顯示編號 | 無 |
| 章節進度 | 顯示目前在第幾章，可點擊跳章 | 點一下 |
| 路徑線 | 金線串起各章，捲到哪亮到哪 | 捲動 |
| 金翼展開 | 金翼隨章節由收攏到全開 | 捲動 |
| 色溫 | 背景由奶油色走到金色 | 捲動 |
| 三階段路線 | 三個節點，一次展開一個 | 點一下 |
| 章末下一步 | 每章結尾一個既有的按鈕 | 點一下 |
| 數字進場 | Hero 信任標記裡的數字由 0 跑到定值 | 捲動 |

### 4.3 深入 CTA

| 項目 | 需求 |
| --- | --- |
| 記住選擇 | 需求入口選的方向存在訪客的瀏覽器；回到首頁時直接顯示那一張卡。不送到伺服器 |
| 會變的固定行動列 | 首頁手機底部固定列的主按鈕依情境改變：預設「從這裡，開始我的改變」（Hero 主按鈕的原文，回到需求入口）；選過方向後改為該方向卡片的第一個按鈕；到第 05 章改為「加入免費體驗社群：密碼168168」。文字全部是既有按鈕文字 |
| LINE 帶話 | 在服務或課程詳細頁，手機上點任何官方 LINE 連結，對話框預先填入該頁的正式名稱。桌機與沒有 JavaScript 時維持原連結。可由 `siteLinks.linePrefill` 全站關閉 |

### 4.4 視覺

這一輪只用自製的 SVG 與 CSS：章節圖像、三階段節點、光點。不載入動畫播放器、不放影片、不用 AI 圖像。客戶素材（RPT-001 G1–G3）與 RES-004 §8 的新缺口到位後，另開批次替換。

### 4.5 量測

| 事件 | 觸發 | 欄位 |
| --- | --- | --- |
| `need_select` | 選擇方向 | `need` |
| `chapter_view` | 某一章第一次進入畫面 | `chapter` |
| `stage_open` | 展開三階段之一 | `stage` |
| `line_click` | 點任何官方 LINE 連結 | `page`、`from`、`prefill` |
| `booking_click` | 點任何預約系統連結 | `page`、`from`、`target` |
| `community_click` | 點免費社群連結 | `page`、`from` |
| `sticky_click` | 點底部固定列 | `page`、`target` |

- 元件只呼叫 `lib/track.ts`，背後的工具可換。
- 這一輪接上 Vercel Web Analytics（延續 2026-10-05 的決策）。腳本只在 Vercel 上載入。
- Vercel 免費方案不支援自訂事件；在升級或換工具前，只有頁面瀏覽會出現在後台（RES-004 §6）。
- Vercel Web Analytics 不使用 Cookie。即使如此，隱私權政策是否需要補述由客戶決定（RES-004 T12）；這一輪不動條文。

## 8. 變更紀錄

### 2026-10-05（二）首頁改為腳本式捲動故事

使用者看過第一版五章首頁後指示：首頁每個區塊都要是互動的，一開始只留很少的文字、主題明確；每個區塊是獨立的 slide，用捲動動畫說故事；以金翼 Logo 為發想（分解說明、飛行）；參考 <https://codepen.io/alyona-mysiura/pen/dygaMRe> 的連貫感；並允許使用第三方資源。

使用者指定的分鏡：Hero → 3D 書（四個對象，捲動打開、可點選翻頁）→ 金翼由下方飛出，陸續遇到三個階段（原本的路徑插圖拿掉）→ 正式介紹創辦人 → 3D 的三本書與 Podcast（點書到媒體專訪）→ 再次邀請加入社群 → 常見問題 → 頁尾。

對本文件的影響：

- §3「不擋路」的「手機不做固定舞台」在首頁不再適用。改為：以原生捲動驅動釘住的 slide，不攔截滾輪、不吸附，每張 slide 釘住的長度要短；沒有 JavaScript 或開啟「減少動態效果」時是一般的直向頁面。RES-004 §4 的易用性風險仍在，上線後以量測與操作錄影檢查。
- §4.1 的五章改為七張 slide，內容與錨點不變。
- §4.4 的「不載入動畫播放器」維持，但加入 GSAP（含 ScrollTrigger 等外掛，免費可商用）。
- 「能量療癒服務」區塊在分鏡中沒有獨立的 slide，去處待使用者確認。
