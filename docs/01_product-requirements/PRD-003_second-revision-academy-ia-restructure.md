## 1. 概觀

官網要從「文齡老師個人品牌＋服務展示」改為「豐盛之翼學苑」的品牌官網。首頁改以訪客需求分流，再導向服務、認證班、官方 LINE 或商城。

開發策略分五段：文案對齊 → UIUX 研究 → 圖文缺口建議書 → 素材到位後實作 → 轉化路徑驗證。本 PRD 定義全部範圍，並標明每一項屬於哪一段。

目標是一個路徑清楚、版面簡約的品牌網站：訪客進首頁後能認出學苑、找到自己的狀態、走到一個明確的下一步。

### 4.9 CTA 導流規則

每個服務、課程、區塊的 CTA 帶一個類型，依下列順序決定目的地（需求書 §19.4）：

1. 有明確商城購買頁 → 商城。
2. 有明確預約或活動頁 → booking 連結。
3. 需確認梯次、資格或細節 → 官方 LINE。
4. 新手、不確定適合哪項 → 官方 LINE 或 `/start`。
5. 沒有正式連結 → 保留文字，標示「連結待補」，不套用無關連結。

CTA 文字依實際行動選用，不全站統一一句。

**手機固定 CTA 列**

- 取代現行右下浮動 LINE 圓鈕，底部固定，最多 2 個按鈕。
- 服務頁：加入 LINE 諮詢＋立即預約／前往商城。
- 認證班頁：了解課程＋加入 LINE 詢問。
- 其他頁：加入 LINE 諮詢＋商城。
- 移除「免費加 LINE 領靜心好禮!」提示文字。

**涉及檔案：** `src/types.ts`、`src/data.ts`、`app/ClientLayoutWrapper.tsx`、各 CTA 所在元件

- 方向：金色、暖光、白色、深色或中性色；學院與專業感；不用粉色。
- 移除 `brand-pink-*` token 與 12 個元件檔約 180 處用法，替代色階由 UIUX 研究定案後一次替換。
- shadcn 元件用到但未定義的語意色 token（`bg-popover`、`text-muted-foreground` 等）在 `app/globals.css` 補齊，取代目前逐元件覆寫色碼的做法。
- 互動行為（選單、Tabs、Accordion、表單、焦點狀態）以 React Aria 的行為為驗收參考。
- 動效採三層系統（功能、敘事、品牌光感），用既有的 `motion` 套件與 CSS 實作，不新增動效套件。規格、缺口與效能底線見 RPT-001 §5；強度待客戶選擇，預設「光感」。
- 設計 token、各頁線框與元件對照以 RES-001 §6–§8 為準。
