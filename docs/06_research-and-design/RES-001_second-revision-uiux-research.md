## 1. 研究目的

階段 A 已讓內容與文案集 v2 一致。本研究在動版型之前回答四個問題：

1. 訪客從進站到 LINE／商城／預約，現在要走幾步、卡在哪裡？
2. 主導覽要怎麼排，才同時滿足需求書與「簡約」？
3. 各頁的區塊順序與元件該長什麼樣？
4. 顏色、字體、元件要先整理到什麼程度，階段 D 才不會邊做邊改？

產出是階段 C（圖文缺口建議書）與階段 D（實作）的依據。本文件不含程式修改。

## 2. 結論摘要

- **首頁太長**。手機版 23.1 個螢幕高，主要內容 26 個對外連結。依決策 D2 移除三個區塊可減 42%，但新增 5 個區塊後會再變長，必須為每個區塊設高度上限。
- **需求入口是首頁最重的區塊**。手機上 4 張卡共 4.9 個螢幕。建議手機版改成分頁切換，一次只顯示一張。
- **詳細頁的預約按鈕太晚出現**。手機上在第 2.5 個螢幕才看得到，且沒有 LINE 替代出口。建議加底部固定 CTA 列。
- **4 個頁面是死路**。`/testimonials`、`/about`、`/story`、`/services` 的主內容沒有任何通往 LINE、商城或預約的出口。
- **全站有兩套視覺語言**。首頁、導覽、頁尾是奶油金色；服務、認證班、關於、部落格等內頁是白底加粉色。這是「粉粉的」的來源，也是品牌不一致的主因。
- **3 組常用配色對比不足**：金色小字連結、輔助說明文字、LINE 綠底白字。
- **導覽採方案 C**：第一層 5 項加 LINE、商城兩顆按鈕，估算 1024px 起就能完整顯示。

### 3.6 其他發現

- **標題階層**：`/about`、`/services`、`/training`、`/testimonials`、`/resources`、`/faq` 沒有 `<h1>`，頁面主標題用的是 `<h2>`。
- **圖片**：全站 0 張圖。Hero 圓框、書封、服務主視覺都是漸層加圖示佔位。
- **字體重複載入**：`app/layout.tsx` 用 `next/font` 載入 Noto Sans／Serif TC，`app/globals.css` 第 1 行又用 `@import` 從 Google Fonts 載入同兩套字。
- **失效的 class**：`animate-fadeIn` 用在 13 個檔案，但沒有任何 CSS 定義它，等於沒有效果。
- **未使用的檔案**：`src/index.css` 沒有被任何地方引用。
- **小點擊目標**（手機，高度低於 40px）：Header 商城按鈕 36px、選單按鈕 32px、頁尾所有連結 23–24px、詳細頁「返回服務總覽」20px。
- **動效**：`motion` 套件只有 1 個檔案使用；全站沒有處理 `prefers-reduced-motion`。
- **shadcn 元件**：已安裝 9 個（button、card、badge、navigation-menu、sheet、popover、separator、info-popover、shimmer-button）。它們依賴的語意色 token（`bg-popover`、`text-muted-foreground` 等）沒有定義，目前靠每個元件各自覆寫色碼。

## 4. 轉化路徑

### 4.1 四條主要路徑

| 路徑 | 訪客 | 理想流程 | 現況步數 | 現況阻礙 |
| --- | --- | --- | --- | --- |
| P1 需求明確 | 知道自己卡在哪 | 首頁 → 需求入口卡 → 服務詳細頁 → 預約 | 3 次點擊 | 詳細頁按鈕太晚出現；沒有 LINE 退路 |
| P2 不確定 | 第一次接觸 | 首頁 → 新手入門 → LINE 諮詢 | 無此路徑 | 新手入門頁不存在；只剩浮動 LINE 鈕 |
| P3 先求信任 | 想先看別人經驗 | 首頁 → 見證或媒體 → 對應服務 → 預約 | 走不通 | 見證頁空白且無出口；媒體頁不導回服務 |
| P4 想學習 | 想取得認證 | 首頁卡 4 → 認證班詳細頁 → 報名或 LINE | 3 次點擊 | 同 P1 |

### 4.2 設計規則

1. **每頁一個主要行動**。同一視窗內最多一顆主按鈕（金色實心），其餘用次要樣式。
2. **不留死路**。每個內容頁的結尾放一條 CTA 區塊：左邊「了解適合我的服務」（導向需求入口或新手入門），右邊「加入官方 LINE 諮詢」。
3. **詳細頁手機版加底部固定列**，兩顆按鈕：該頁的預約／報名，加上 LINE 諮詢。固定列出現時隱藏浮動 LINE 圓鈕，避免重複。
4. **信任內容要指回服務**。每則見證標示對應服務並可點擊；媒體頁在出版品與訪談之間插入一條導向服務的區塊。
5. **首頁出口收斂**。首頁對外連結由 26 個降到 10 個以內：Hero 2、需求入口每卡 2、最終 CTA 2。服務與課程的預約連結只留在詳細頁。
6. **CTA 文字依行動命名**，沿用 PRD-003 §4.9 的分流規則。

### 4.3 階段 E 量測定義

事件 `cta_click`，欄位：`destination`（line／shop／booking／community）、`page`、`section`、`label`。

| 指標 | 定義 |
| --- | --- |
| 需求入口點擊率 | 點擊任一需求入口 CTA 的工作階段 ÷ 首頁工作階段 |
| 詳細頁轉出率 | 在詳細頁點擊預約或 LINE 的工作階段 ÷ 詳細頁工作階段 |
| 全站轉出率 | 有任一 `cta_click` 的工作階段 ÷ 全部工作階段 |
| 各出口占比 | LINE、商城、預約、社群四種目的地的點擊分布 |

量測工具採 Vercel Web Analytics（§9 決策 6）；方案是否包含自訂事件待確認，見 RPT-001 §6。

## 5. 導覽方案

三個方案都符合需求書 §19.1 的必做項：「療癒與培訓」下有三個入口、媒體專訪有入口、有明顯的商城按鈕。

| | A 平鋪（階段 A 現況） | B 三組 | C 建議 |
| --- | --- | --- | --- |
| 第一層 | 首頁／關於我們▾／療癒與培訓▾／客戶見證／媒體專訪／部落格／免費資源／聯絡我們 | 關於我們▾／療癒與培訓▾／見證與內容▾／聯絡我們 | 關於我們▾／療癒與培訓▾／客戶見證／媒體專訪／更多▾ |
| 按鈕 | 商城 | 商城 | LINE 諮詢、商城 |
| 第一層項目數 | 8 | 4 | 5 |
| 完整顯示的最小寬度 | 1280px（實測導覽本體 674px） | 1024px | 1024px（估算，需實作驗證） |
| 1024–1279px | 退成抽屜選單 | 完整顯示 | 完整顯示 |
| 信任內容（見證、媒體） | 第一層 | 藏在下拉 | 第一層 |
| 與需求書 §3.1 | 完全一致 | 分組不同 | 少「首頁」；部落格、免費資源、聯絡收進「更多」 |
| 與客戶 8 月「按鈕不要那麼多」 | 相反 | 符合 | 符合 |

**採方案 C**（2026-10-05 確認），理由：

- 「首頁」由 Logo 承擔，不需要佔一格。
- 見證與媒體是建立信任的內容，值得留在第一層；部落格與免費資源是延伸閱讀，可以收起來。
- 聯絡的第一順位本來就是 LINE（需求書 §20.11），直接給一顆 LINE 按鈕比「聯絡我們」文字連結更短。聯絡頁仍在「更多」與頁尾。
- 平板橫向與小筆電不必退成漢堡選單。

「更多」下拉內容：部落格、免費資源、聯絡我們。「療癒與培訓」下拉：新手入門（頁面上線後）、全部服務、認證班。

手機抽屜維持完整列出全部頁面，底部固定商城與 LINE 兩顆按鈕（已實作）。

4. Tabs：Podcast／直播訪談／合作單位。Podcast 內依節目分組，集數超過 5 集的節目預設收合。
5. CTA 區塊。

### 6.10 免費資源、聯絡我們、部落格

- **免費資源**：3 張資源卡加社群橫幅，結構不變，換成統一卡片樣式。
- **聯絡我們**：現行導流卡片即可，不需再改版型。
- **部落格**：文章去留未定（PRD-003 §7 第 10 項），版型暫不動，只換色。

## 7. 設計 token

### 7.1 方向

金色、暖光、奶油白為主；深咖啡色作為重點區塊與頁尾；不使用粉色。全站統一成現有的「奶油金」語言，內頁的白底粉金語言整組淘汰。

### 7.2 語意 token

在 `app/globals.css` 定義下列 token，元件只用語意名稱，不再寫色碼。這同時補齊 shadcn 元件缺少的變數。

| Token | 值 | 用途 |
| --- | --- | --- |
| `background` | `#FBF1DD` | 頁面底 |
| `foreground` | `#2E2318` | 內文 |
| `card` | `#FDF6E6` | 卡片底 |
| `card-foreground` | `#3A2A18` | 卡片標題 |
| `popover` | `#FFFDF0` | 下拉、浮層、強調卡 |
| `primary` | `#C9862E` | 主色（金） |
| `primary-foreground` | `#3A2409` | 金底上的文字 |
| `secondary` | `#FFFDF0` | 次要按鈕底 |
| `secondary-foreground` | `#8A5415` | 次要按鈕文字 |
| `muted` | `#FDF6E6` | 弱化底 |
| `muted-foreground` | `#7A6650` | 輔助文字（取代 `#9A8060`） |
| `accent` | `#FCE7A8` | 選中、hover 底 |
| `accent-foreground` | `#8A5415` | 選中文字、小字連結（取代 `#B5762A`） |
| `border` | `#F0DFA0` | 邊框 |

### 7.3 對比修正

| 問題 | 修正 | 修正後對比 |
| --- | --- | --- |
| 金色小字 `#B5762A` | 一般大小的文字改用 `#8A5415`；`#B5762A` 只用於圖示、邊框與 18px 以上標題 | 5.57–5.80 |
| 輔助字 `#9A8060` | 改用 `#7A6650` | 4.87–5.07 |
| LINE 綠底白字 | 維持 LINE 綠 `#06C755`，文字改深綠 `#0B2E18` | 6.56 |
| 頁尾弱字 `#8A7458` | 改用 `#A08660` | 5.21 |

### 7.4 粉色替換對照

| 現有 | 替換 |
| --- | --- |
| `brand-pink-600`／`700`（文字、連結） | `accent-foreground`（`#8A5415`） |
| `brand-pink-500`（圖示） | `ring`（`#B5762A`） |
| `brand-pink-50`／`100`（底色、邊框） | `muted`／`border` |
| 粉到金的漸層（分隔線、按鈕） | 金色漸層（沿用 `.gold-btn` 的色階） |
| `bg-white`、`stone-*` | `card`／`popover`／`muted-foreground` |

替換後移除 `brand-pink-*` 與 `brand-stone-*` 定義。

### 7.5 字體與間距

- 標題 Noto Serif TC、內文 Noto Sans TC，維持不變。移除 `globals.css` 的重複 `@import`。
- 字級收斂為 5 級：H1 32/40、H2 26/32、H3 20、內文 16、註記 14（手機／桌機）。
- 區塊上下間距統一：手機 64px、桌機 96px。
- 卡片圓角統一 18px；按鈕全圓角。
- 點擊目標最小高度 44px，包含頁尾連結與 Header 按鈕。

### 7.6 動效

- 進場：區塊捲入視窗時淡入上移一次，200–300ms，不重複觸發。
- Hero 的光點閃爍保留，其餘區塊不加持續性動畫。
- 一律尊重 `prefers-reduced-motion`。
- 移除無效的 `animate-fadeIn`，改用一個共用的淡入元件。

完整的動效分層（M1–M4）、逐區塊規格、開發端缺口與效能底線見 [`RPT-001`](../05_audits-and-reports/RPT-001_content-asset-and-motion-gap-proposal.md) §5。上面「其餘區塊不加持續性動畫」一條，在客戶選擇「光感」強度時放寬為：同一畫面最多 2 個持續循環的動效。

## 11. 研究限制

- 沒有真實流量數據，轉化路徑的判斷來自結構分析，不是使用者行為。
- 高度與點擊目標在本機開發伺服器量測，未在實機上驗證。
- 方案 B、C 的導覽寬度是依方案 A 的實測值估算。
- 預覽視窗在背景時不觸發動畫幀，部落格頁因此停在「載入中」；PLN-004 §7.5 記錄的「錨點直接載入不捲動」可能是同一個原因，需在一般瀏覽器重新確認。
