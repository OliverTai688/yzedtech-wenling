# `/media` 媒體專訪

**批次：** P4　**日期：** 2026-10-06　**簡報：** [`../BRIEF.md`](../BRIEF.md)　**提案：** [`index.html`](./index.html)

HTML 由資料檔（`src/data.ts`）直接帶出文字與 34 集的連結，沒有手打的字。

## 1. 現況（手機 390×844，改版前）

| 項目 | 數字 |
| --- | --- |
| 頁面長度 | 5229px（6.2 個畫面） |
| 各畫面內文字數 | 150、154、20、0、70、0（上限 140，前兩個畫面超過） |
| 單一畫面的按鈕 | 1 顆金色（夾在出版品與訪談中間的卡片） |
| 站外連結 | 43 個（37 個不重複） |
| 第一個畫面 | 五行的 H1 加三行說明，接著就是第一本書的整段介紹；沒有視覺焦點，也看不出下面有幾個區塊 |
| 節目清單 | 11 列同時出現，單一畫面最多 11 個可點的東西（上限 8） |
| 下一站 | 沒有 |

問題：三本書的三段長說明同時攤開（前兩個畫面各 150 字以上）；書封的佔位是寫死色碼的漸層；11 個節目一次列完。

## 2. 這一頁的旅程角色

- 訪客為什麼來：想看外界怎麼說（從「真實見證」過來，或從首頁的媒體區）。
- 這一頁要他做的事：看到可查證的紀錄。這一頁不放金色按鈕：訪客要的是佐證，每一列都是往外的連結；`從這裡，開始我的改變` 在結尾的行動區塊裡。
- 上一站：真實見證　下一站：服務項目。

## 3. 做法

1. **第一個畫面**（`PageHero`）：眉批「媒體專訪與出版紀錄」、H1（文案集的標題）、一句導言，下面是**頁內小導覽**：四個區塊既有的標題（出版品、Podcast 精選訪談、Podcast / 訪談、官方授權認證資歷與合作機構）。
2. **出版品**（`#media-books`）：三本書各一列，整列是收合的標題：**文字封面**（直排書名，`data-placeholder="book-cover"`，沒有圖片）加文案集的整行標題（書名與角色），第三本另有「曾創下 2022 年度收聽冠軍、2024 前十名！」。長說明與購買連結在收合裡，**一次開一本**（原生 `<details name>`），預設開第一本。
3. **Podcast 精選訪談**（`#media-podcasts`，錨點不變）：六集精選，每列是一個往外的 `.btn-text`：節目名稱（小字）加單集標題。
4. **Podcast / 訪談**（`#media-shows`）：11 個節目是**分頁**（`ChipTabs`），一次看一個節目的單集；有說明的節目先列一句說明。「好女人的情場攻略 Podcast」有 14 集，依文案集的季別（2020 S1、2022 S3、2024 S5）再收合，一次開一季。沒有連結的那一集只列標題與「連結待更新」。
5. **官方授權認證資歷與合作機構**（`#media-partners`）：三行條列。
6. **下一站**（`JourneyNext`）。

沒有 JavaScript 時：三本書照樣可以開合；11 個節目全部攤開，各自帶著節目名稱。

## 7. 未解的問題

- 書封素材（RPT-001 G3）到位後，把文字封面換成圖片即可，版面不變。
- 「共煮生活實驗室」那一集的連結待客戶確認。
