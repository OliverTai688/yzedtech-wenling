# `/blog` 好運blog

**批次：** P4　**日期：** 2026-10-06　**簡報：** [`../BRIEF.md`](../BRIEF.md)　**提案：** [`index.html`](./index.html)

## 1. 現況（手機 390×844，改版前）

| 項目 | 數字 |
| --- | --- |
| 頁面長度 | 1824px（2.2 個畫面） |
| 單一畫面最多內文 | 0 字 |
| 內容 | 只有頁名，接著就是結尾的行動區塊 |
| 下一站 | 沒有 |

現有的 6 篇文章不在文案集裡，依「全站文字只能出自 docx」的規定不顯示（`SHOW_BLOG_POSTS = false`）。問題：頁面是死路，而且頁名貼著頁首，沒有第一個畫面的樣子。

## 2. 這一頁的旅程角色

- 訪客為什麼來：想讀文章（目前沒有文章）。
- 這一頁要他做的事：沒有按鈕。
- 上一站：媒體專訪　下一站：免費資源。

## 3. 做法

1. **第一個畫面**（`PageHero`）：金翼小標誌與 H1「好運blog」。沒有導言、沒有按鈕；文案集沒有「尚無文章」的句子，所以不寫任何說明。
2. **下一站**（`JourneyNext`）：媒體專訪、免費資源。
3. 結尾的行動區塊。

文章的程式另外放在 `src/components/blog/BlogPosts.tsx`，只有 `SHOW_BLOG_POSTS` 為 `true` 時才載入：分類篩選（`.chip`）、最新一篇露出摘要、其餘只列標題，點了用共用的面板（`PageSheet`）閱讀。開關關閉時，文章的文字不進 HTML。

## 4. 量測（提案，手機）

| 項目 | 現況 | 提案 |
| --- | --- | --- |
| 頁面長度 | 1824px | 1946px |
| 單一畫面最多內文 | 0 | 0 |
| 單一畫面的金色按鈕 | 1（結尾區塊） | 1（結尾區塊） |
| 可點的東西 | 0 | 2（上一站、下一站） |

比現況長 122px：多了第一個畫面的小標誌（80px）與「下一站」一列（77px），兩個都是簡報規定每頁要有的；頁面只有這兩樣，沒有可以再拿掉的東西。

### 實作後（`http://localhost:3100/blog`，手機）

- 長度 1947px；一個 H1；上一站與下一站各一個連結；五種寬度沒有橫向捲軸與主控台錯誤；文案比對只剩「開啟選單」。
- 伺服器送出的 HTML 裡沒有任何文章的文字，也沒有「全部」「閱讀全文」（用 `curl` 檢查）。
- 文章區在本機暫時打開開關看過一次（量完已還原）：分類篩選、最新一篇、清單、面板閱讀都正常。文章內文裡有 Markdown 記號（`**`、`###`）會原樣顯示，文章核可時要一併處理。
