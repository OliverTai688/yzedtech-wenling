# `/testimonials` 真實見證

**批次：** P4　**日期：** 2026-10-06　**簡報：** [`../BRIEF.md`](../BRIEF.md)
**提案：** [`index.html`](./index.html)（未授權，現在上線的狀態）、[`authorized.html`](./authorized.html)（客戶授權後才上線）

兩份 HTML 都由資料檔（`src/data.ts`）直接帶出文字，沒有手打的字。

## 1. 現況（手機 390×844，改版前）

| 項目 | 數字 |
| --- | --- |
| 頁面長度 | 2438px（2.9 個畫面） |
| 單一畫面最多內文 | 0 字（量測不計連結內的文字；實際看得到三段服務說明約 96 字） |
| 單一畫面的按鈕 | 1 顆金色＋1 個文字連結（私訊官方 LINE） |
| 第一個畫面 | 只有頁名與兩個行動，沒有視覺焦點，和其他內頁的第一個畫面不是同一個樣子 |
| 下一站 | 沒有 |

問題：頁面沒有見證（授權未到），但版面仍然是「標題＋兩個按鈕＋一張服務清單」，看不出這一頁的角色；程式是用戶端元件，見證文字雖然沒有畫出來，仍會被打包進瀏覽器的程式。

## 2. 這一頁的旅程角色

- 訪客為什麼來：想看別人的結果（從「創辦人經歷與故事」或服務詳細頁過來）。
- 這一頁要他做的事：`從這裡，開始我的改變`（回首頁選對象）。
- 上一站：創辦人經歷與故事　下一站：媒體專訪（同樣是外界的佐證，所以未授權時這一頁不是死路）。

## 3. 做法

### 未授權（`homeContent.testimonials.authorized = false`）

1. **第一個畫面**（`PageHero`）：金翼小標誌、H1「真實見證」、一顆金色按鈕。文案集沒有「見證整理中」的句子，所以沒有導言。
2. **去哪裡**（`PageSection`）：標題是首頁服務區的原標題，下面三列服務（`homeContent.services.ids`），每列是一個 `.btn-text` 連結，只有服務名稱加箭頭；最後一列是「服務項目」。上一版每列下面的一句說明拿掉了，第一個畫面因此安靜下來，長度也回到現況以內。
3. **下一站**（`JourneyNext`）。
4. HTML 裡沒有任何見證文字、沒有見證區的標題。

### 授權後（`authorized = true`）

1. 第一個畫面多一句導言（`description`）。
2. 見證區：標題（`heading`）→ **分頁**（`ChipTabs`，四個分類）→ **一次一則**（`Pager`，每類兩則；箭頭的無障礙名稱是要去的那一則的來源）→ 該分類相關的服務連結（`.btn-text`）。
3. 授權後不再列三項服務，改由每個分類自己的連結帶去服務。

分類與服務的對應（只有對應關係，連結文字與網址取自 `needEntries` 既有的第一個 CTA）：

| 分類 | 對象入口 | 連結 |
| --- | --- | --- |
| 感情／單身 | 感情 | 了解心靈引渡人 → `/services/personal-1on1` |
| 家庭／媽媽 | 家庭 | 了解人生推進器 → `/services/group-healing` |
| 事業／企業主 | 事業 | 了解豐盛靈氣 → `/services/abundance-reiki` |
| 身心蛻變／其他 | 新手 | 了解希塔療癒 → `/training/theta-basic` |

沒有 JavaScript 時：四個分類全部攤開、每類的兩則直向列出，箭頭不顯示。

### 實作後（`http://localhost:3100/testimonials`，手機）

| 項目 | 未授權（上線中） | 授權後（在本機暫時打開開關量測，量完已還原） |
| --- | --- | --- |
| 頁面長度 | 2421px | 2688px |
| 單一畫面最多內文 | 0 | 68 字 |
| 單一畫面的金色按鈕 | 1 | 1 |
| 單一畫面可點的東西 | 7 | 6 |

- 未授權時伺服器送出的 HTML 裡沒有 `blockquote`、沒有任何一則見證與見證區的標題（用 `curl` 檢查）。
- 授權後的互動（puppeteer）：分類切換、翻頁、箭頭的無障礙名稱、關閉 JavaScript 後八則全部可見。
- 共用的 `Pager` 有一個鍵盤問題：翻到最後一則時「下一則」按鈕變成停用，焦點會離開翻頁列（`activeElement` 變成 `body`；每類只有兩則時一定遇到）。這是共用元件，沒有動，交主代理處理。
- 文案比對：只剩「開啟選單」。四條路徑的 P3（見證／媒體 → 服務）全部通過。

## 5. 與上一版（RES-002 §8）的差異

- 第一個畫面改用共用的 `PageHero`；私訊官方 LINE 的文字連結拿掉（緊接著的結尾區塊就是私訊按鈕）。
- 授權後由「一類一組卡片並排」改成「一類一次一則」。
- 元件改成伺服器元件：未授權時見證文字不進 HTML，也不進瀏覽器的程式。
- 這一頁沒有手機底部固定列（頁面短，固定列會和結尾區塊的金色按鈕同時出現）。

## 7. 未解的問題

- 見證授權（RPT-001 C1）。授權後把 `authorized` 改成 `true` 即可，頁面不需再改。
- 分類與服務的對應是元件裡的判斷，需客戶確認（特別是「身心蛻變／其他」對到希塔療癒課程）。
- 未授權時沒有導言：若客戶提供一句說明，可以放在 H1 下面。
