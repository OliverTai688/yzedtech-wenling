問題：

- 加入密碼夾在第一張卡片裡，不是第一眼看到的東西；每週時段在第二張卡片的條列裡。

## 2. 旅程角色

訪客想先免費試試。這一頁只要他做一件事：加入免費社群。上一站「培訓課程」，下一站「服務項目」。

## 3. 分層的做法

1. **第一個畫面**（`PageHero`）：頁名、說明的第一句、唯一的金色按鈕「加入免費體驗社群：密碼168168」。按鈕下方是一張「票卡」：`168168`、`21:30`、`20:30` 三組大數字，各配一行原文的小字。這是這一頁的視覺焦點。
2. **三個步驟**：原生 `<details name>`，一次開一個，第一步預設展開。標題前是 1、2、3。每一步自己的行動是 `.btn-text`（加入社群、點我加入社群、私訊官方 LINE）。
3. **手機底部固定列**：金色那顆是加入社群，銀色圓鈕是私訊。捲過第一個畫面後出現。
4. `JourneyNext`、`CtaBand`。

## 4. 原文怎麼安排（沒有刪句，沒有新字）

| 原文（`src/data.ts` `resources`） | 位置 |
| --- | --- |
| `intro` 第一句（到「！」為止） | 第一個畫面的導言 |
| `intro` 第二句（社群內每週…小禮物 。） | 第二步的內文 |
| 第一步 `highlight`「加入密碼：168168」 | 票卡：以「：」拆成小字與大數字 |
| 第二步 `list` 有時段的兩項 | 票卡：以「：」與空白拆成名稱、星期、時間 |
| 第二步 `list` 沒有時段的一項 | 留在第二步 |
| 各步的 `title`、`description`、`ctaText` | 各步的標題、內文、文字連結 |

拆字在元件裡用程式做（依「：」與空白），資料檔不動。
