# 首頁敘事化 `/`（PLN-005 F2；主題「改變地圖」）

首頁已依 RES-002 §1 實作。這一輪不改文案、不改路由，只把並列的區塊改成同一個故事的五個章節，並把 CTA 做深。

## 不能變的

- **文案逐字沿用**，一個字都不新增。所有文字取自 `src/data.ts`（`heroContent`、`needEntriesIntro`、`needEntries`、`homeContent`、`serviceBlurbs`、`mediaIntro`、`mediaPublications`、`resources`、`siteLinks`）與 `src/content/pages.ts`（`pageContent.about` 第 4 個 section「這些技術之間的關係是什麼？可以搭配使用嗎？」的三階段）。章節標示只能用數字 01–05 加上既有的區塊標題或眉標，不可自創章名、口號、按鈕文字。
- **路由與錨點不變**：`#personas-section`、`#featured-services`、`#founder`、`#media-section`、`#free-resources`、`#home-faq` 都要保留。
- 遵守 `../BRIEF.md` 全部規則，特別是 §4A 文字密度（手機單一畫面內文約 100 字、桌機約 150 字）。
- 使用 `../_kit.css` 的 token 與 `../_shell.html` 的外殼（頁首、頁尾）。

## 要設計的

1. **章節感**：章與章之間看得出前後關係（路徑、進度、色溫由奶油色走到飽和的金色）。金翼羅盤是視覺主角，隨章節由收攏到全開。
2. **每章結尾有一個「下一步」**：用該章已有的按鈕文字（例如「查看全部服務」「認識創辦人」「閱讀媒體專訪」「查看免費資源」），不新增文字。
3. **會變的手機底部固定列**：左邊主按鈕的文字與連結隨章節或所選方向改變（只能用既有按鈕文字：「了解適合我的服務」、所選方向卡片的第一個按鈕文字、「加入免費體驗社群：密碼168168」、「加入官方 LINE 諮詢」），右邊固定是「LINE 諮詢」。
4. **三階段的呈現**：三個階段各有一段約 80–110 字的原文，內含粗體技術名稱。要讓三個階段的先後關係一眼可見，原文點開才看（一次開一個）。
5. **小而多的互動**，每一個只需要捲動或點一下。可考慮：章節進度指示、數字進場（「500+個案經驗」「整合14種以上顯化技術…」的數字）、選擇方向後羅盤指針轉向並被記住、光點或羽毛等 SVG／CSS 小動畫。

## 不能做的

- 不可改變捲動速度、方向或整頁吸附。手機不做固定舞台（sticky 場景）。桌機若用固定舞台，只能在第一屏以下、以圖像為主、不超過兩個螢幕高，文字不放在舞台內。
- 不放照片（素材未到）；視覺用 SVG 與 CSS 自製。不載入外部圖片、字型以外的資源、動畫播放器或 three.js。
- 見證區不顯示（未授權）。
- `prefers-reduced-motion` 時全部直接顯示完成狀態。
